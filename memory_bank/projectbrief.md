# Project Brief

## Project Overview
**Название проекта:** linklayer  
**Ссылка на репозиторий:** https://github.com/scov3/linklayer  
**Текущий статус:** Система графов реализована (классический + физический режим + редактор связей)  
**Дата инициализации:** 14 марта 2026 года  
**Процент выполнения:** 59% (8 deliverables completed, 2 in_progress)

**Краткое описание:**  
Умный блокнот с системой графов для управления знаниями. Реализованы: авторизация, CRUD заметок, теги, классический граф (Cytoscape), физический граф (d3-force + canvas), редактор связей между заметками. В работе — финальная отладка графов.
